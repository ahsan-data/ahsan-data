## My Approach to Data Analysis

1. **Define the question.** Understand the problem the analysis needs to address.
2. **Inspect the data.** Check structure, completeness, consistency, and quality.
3. **Clean and validate.** Apply appropriate transformations and verify the results.
4. **Analyze the evidence.** Use relevant queries, calculations, and comparisons.
5. **Communicate findings.** Present results clearly and explain their practical meaning.
